h1. Decision Engine API - Knowledge Transfer Document

(toc:minLevel=1|maxLevel=4)

----

h2. 1. Overview

This API acts as a Decision Engine orchestration layer:

- Fetches request (shortJSON) from DB
- Builds DAJSONDocument (PCSM input)
- Executes all blocks in parallel
- Calls PCSM (NTJSEMJSONInterface - sp5 jar)
- Performs post-processing
- Stores response in DB
- Returns final summarized response

*Notes:*
- Core class: DecisionServiceImpl
- Models from SMPOJO jar
- PCSM call via sp5 jar

----

h2. 6. Parallel Execution (Actual Implementation)

{code}
Request
   ↓
Create 20 Callable Tasks
   ↓
executor.invokeAll(tasks, timeout)
   ↓
validateFutureList()
   ↓
Tasks directly update PcsmRequest
   ↓
DAJSONDocument ready
{code}

*Notes:*
- No Future.get()
- No aggregation layer
- Shared mutable PcsmRequest
- Validation checks:
  - isDone()
  - !isCancelled()
  - executionErrorMsg empty

h2. 11. Exception Handling

{code}
Exception
   ↓
ControllerExceptionHandler
   ↓
StrategicDecisionException
   ↓
storeErrorResponse()
   ↓
Return Error Response
{code}

Error Codes:

- DES001 → DB failure
- DES002 → Task failure
- DES003 → PCSM failure
- DES004 → JSON parsing error
- DES100 → Business validation

*Notes:*
- Centralized handling
- Always logs + stores error

h2. 14. Adding New Block (Important)

|| # || Location || Change || Risk ||
| 1 | SMPOJO | Model update | Block missing |
| 2 | ApiConstants | Add constant + EXPECTED_TASK_COUNT | DES002 |
| 3 | PcsmConfiguration | Add block | Task missing |
| 4 | CSV | Add mapping | Wrong data |
| 5 | Config | ConfigRecord | Init fail |
| 6 | Block | Converter | Mapping fail |
| 7 | Sequence | BodySequence | Not executed |
| 8 | Mapper | JsonMapper | Missing values |
| 9 | Task | Executor | Block skipped |

*Notes:*
- EXPECTED_TASK_COUNT mismatch = production failure
