h1. Decision Engine API - Knowledge Transfer Document

(toc:minLevel=1|maxLevel=4)

----

h2. 1. Overview

- Fetches request (shortJSON) from DB  
- Builds DAJSONDocument (PCSM input)  
- Executes blocks in parallel  
- Calls PCSM (NTJSEMJSONInterface - sp5 jar)  
- Performs post-processing  
- Stores response in DB  
- Returns summarized response  

*Key Notes:*
- Core class: DecisionServiceImpl  
- SMPOJO jar → DAJSONDocument and models  
- sp5 jar → PCSM execution  

----

h2. 2. Controller Layer (DecisionController)

# Validates request type using *DesType.isRequest()*  
# Extracts *productAppId*  
# Starts SLA timer (*StrategicDecisionTime*)  
# Sets MDC context (*productAppId*, *correlationId*)  
# Delegates to *DecisionServiceImpl.callDecisionEngine()*  
# Logs total execution time  

{code:java}
MDC.put(PRODUCT_APP_ID, productAppId);
MDC.put(CORRELATION_ID, correlationId);
{code}

*Key Notes:*
- MDC enables request-level log tracing across parallel execution  
- Controller handles only validation and delegation  

----

h2. 3. End-to-End Flow

{code}
Client Request
   ↓
DecisionController
   ↓
DecisionServiceImpl.callDecisionEngine()
   ↓
fetchAndValidateRequest()
   ↓
processJsonData()
   ↓
createPcsmRequest()
   ↓
executeParallelTasks()
   ↓
executor.invokeAll()
   ↓
validateFutureList()
   ↓
createInputJsonStream()
   ↓
executePcsmRequest()
   ↓
addEntryToIf024JsonDtls()
   ↓
handleSuccessfulResponse()
      ↓
      checkBusinessControlErrors()
      ↓
      generateExtract()
      ↓
      validateTimeTakenByRequest()
      ↓
      storeDesResponce()
   ↓
createFinalResponse()
   ↓
Return Response
{code}

*Key Notes:*
- Tasks directly update PcsmRequest (no aggregation)  
- Extract generation handled in generateExtract()  
- Reference: [Extract Generation Process|<ADD_EXTRACT_URL>]

h2. 6. PARAMTER Caching

{code}
Application Startup
   ↓
SdsParameterMapperImpl (@PostConstruct)
   ↓

Request Flow
   ↓
SdsParameterTask
   ↓
PcsmInitDataBlock → DAJSONDocument

*Key Notes:*
- Loaded once at startup  
- No DB call during request  
- Uses parameterChangeDateTime

h2. 11. PARAMTER Mapper Generation

h3. Folder Setup

{code}

   ├── PARAMTER-UPDATED.csv
   ├── SdsParameterJsonMapperGenerator.java
   ├── SdsParameterJsonMapperImplGenerator.java
{code}

h3. Step 1 – Prepare CSV

- Ensure correct structure  
- No missing fields  

h3. Step 2 – Generate Mapper

{code}
javac SdsParameterJsonMapperGenerator.java
java SdsParameterJsonMapperGenerator
{code}

h3. Step 3 – Generate Impl

{code}
javac SdsParameterJsonMapperImplGenerator.java
java SdsParameterJsonMapperImplGenerator
{code}

h3. Step 4 – Move Files

- Move to mapper package  

h3. Step 5 – Validate

- Build project  
- Verify mappings  

*Key Notes:*
- Never edit generated files  
- Regenerate on CSV change  
- Alignment is critical

- DES100 → Validation  

*Key Notes:*
