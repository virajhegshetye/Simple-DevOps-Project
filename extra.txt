h1. Decision Engine API â€“ Knowledge Transfer Document

----

{panel:title=Flow Summary|borderColor=#0052CC|titleBGColor=#0052CC|titleColor=#FFFFFF}
DB â†’ BLOB to Map â†’ PcsmRequest â†’ 20 Parallel Tasks â†’ PCSM Engine â†’ BControl Check â†’ Extract â†’ Store â†’ Response
{panel}

This application is a *Decision Engine Integration System* built using Spring Boot. It integrates with the Experian PCSM Decision Agent to perform credit decisioning for card applications.

----

h2. 1. High Level Overview

*What this system does:*
* Fetch request JSON from Database (BLOB)
* Transform JSON into structured data blocks
* Execute Decision Engine (PCSM / Experian DA)
* Store response back to Database
* Return final response to caller

*Technology Stack:*
||Component||Technology||
|Framework|Spring Boot|
|JSON Processing|FastJSON2|
|Database|Oracle (JdbcTemplate + JPA)|
|Decision Engine|Experian PCSM (NTJSEMJSONInterface)|
|Parallel Execution|ExecutorService (ThreadPoolTaskExecutor)|
|Object Mapping|MapStruct|

h3. Step 8 â€“ How Each Task Works (Per Block)

Each task follows the same internal pattern using {{AbstractDataBlockTask}}:

# *Extract* â€” get block data from {{pcsmRequest.getJsonAsMap()}}
# *Validate* â€” check block is not null/empty
# *Merge defaults* â€” {{sequence.getAllDefaults()}} + input data
# *Transform* â€” {{commonUtils.parseObject()}} â†’ strongly typed POJO
# *Set* â€” {{pcsmRequest.getDaJsonDocument().setXxxBlock(obj)}}

{expand:title=AbstractDataBlockTask â€” Base Pattern}
{code:java}
public abstract class AbstractDataBlockTask implements Callable<PcsmRequest> {

    protected PcsmRequest pcsmRequest;
    protected String blockName;

    @Override
    public PcsmRequest call() {
        try {
            Map<String, Object> blockData = extractBlockData();
            validateBlockData(blockData);
            Object blockObject = transformToObject(blockData);
            setBlockInDocument(blockObject);
            return pcsmRequest;
        } catch (Exception e) {
            LOGGER.error("Error processing block: {}", blockName, e);
            pcsmRequest.getExecutionErrorMsg().add(blockName + ": " + e.getMessage());
            return pcsmRequest;
        }
    }

    protected abstract Map<String, Object> extractBlockData();
    protected abstract void validateBlockData(Map<String, Object> data);
    protected abstract Object transformToObject(Map<String, Object> data);
    protected abstract void setBlockInDocument(Object blockObject);
}
{code}
{expand}

h2. 3. Error Handling Strategy

h3. Error Codes

||Error Code||Trigger||
|DES001|DB fetch returns null/empty, processing flag not SUCCESS, DB store failure|
|DES002|Task bean not found, task list size mismatch, task execution errors in any block|
|DES003|PCSM non-zero return, BControl errors, SLA timeout exceeded, response parse failure|
|DES004|BLOB null/empty, JSON parse failure, JSON map size != 1|
|DES100|Missing seqNumber or paramChangeDateTime in SPAREFIELD, extract generation failure|
|BAD_REQUEST|Message type not DES_REQUEST|
|PCSM_ERROR|Uncaught unexpected exception|

h3. Error Isolation

{panel:title=Three-Level Error Handling}
*Level 1 â€” Service Layer (DecisionServiceImpl)*
{code:java}
} catch (SQLException e) {
    this.storeErrorResponse(productAppId);
    throw new StrategicDecisionException(DES001, errorMessage);
} catch (StrategicDecisionException e) {
    this.storeErrorResponse(productAppId);
    throw switch (e.getStrategicDecisionErrors().getCode()) {
        case "DES002" -> new StrategicDecisionException(DES002, e.getErrorMessage());
        case "DES003" -> new StrategicDecisionException(DES003, e.getErrorMessage());
        // ... etc
        default       -> new StrategicDecisionException(DES001, e.getErrorMessage());
    };
} catch (Exception e) {
    if (e instanceof InterruptedException) Thread.currentThread().interrupt();
    this.storeErrorResponse(productAppId);
    throw new StrategicDecisionException(PCSM_ERROR, errorMessage);
}
{code}

*Level 2 â€” Task Level (per block)*
Exceptions caught inside each task. Error added to {{executionErrorMsg}} on {{PcsmRequest}}. Task always returns â€” never throws.

*Level 3 â€” Validation*
Missing fields or structure mismatches caught by {{CommonUtils.areMapsSame()}} and {{validateFutureList()}}.
{panel}

h2. 10. Adding a New Block â€” Complete Checklist

{warning}
*All 9 changes below are required.* Missing any one will cause failures â€” some silent.
{warning}

||#||Where||What to Change||Risk if Skipped||
|1|*SMPOJO jar*|Add new block model class + add field to {{DAJSONDocument}}. Rebuild GitLab pipeline, update dependency version.|Compile error â€” block type unavailable|
|2|*ApiConstants.java*|Add new block name constant *AND* increment {{EXPECTED_TASK_COUNT}} (currently 20)|Task count check throws DES002 â€” misleading error, hard to debug|
|3|*PcsmConfiguration.java*|Add new constant to {{DATABLOCKNAMES}} list|Block silently never executes â€” no error thrown|
|4|*resources/configs/*|Add {{NEWBLOCK.csv}} with field schema|BodySequence @PostConstruct fails at startup|
|5|*block.config/*|Add {{NewBlockConfigRecord.java}}|CSV to Java mapping unavailable|
|6|*encoder.converter/block/*|Add {{NewBlock.java}}|Encoder/converter layer incomplete|
|7|*sequence/*|Add {{NewBlockBodySequence.java}} with @PostConstruct|No defaults available â€” task merge step fails|
|8|*model/mapper/*|Add {{NewBlockJsonMapper.java}} (MapStruct interface)|Map â†’ POJO conversion unavailable|
|9|*service/impl/executorTasks/*|Add {{NewBlockTask.java}} (@Component, @Scope PROTOTYPE)|Spring {{getBean()}} throws BeansException â†’ DES002|

{info}
