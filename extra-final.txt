h1. Decision Engine API - Knowledge Transfer Document

(toc:minLevel=1|maxLevel=4)

----

h2. 1. Overview

This service acts as a Decision Engine API that:

- Fetches request data (shortJSON) from DB
- Builds full PCSM input JSON
- Calls PCSM (NTJSEMJSONInterface)
- Processes response (outputJSON)
- Returns summarized response to client

----

h2. 2. High Level Flow

{code}
Client Request
   ↓
DecisionController
   ↓
DecisionServiceImpl
   ↓
fetchAndValidateRequest()
   ↓
shortJSON (DB)
   ↓
Sequence Execution (Tasks)
   ↓
Build DAJSONDocument
   ↓
Call PCSM API
   ↓
Receive outputJSON
   ↓
Build Response
   ↓
Return to Client
{code}

h2. 6. PARAMTER Block Handling (Critical Section)

- PARAMTER block size = 5302 fields
- Comes from DB (VecSdsparam table)
- Mapped using SdsParameterMapper

Flow:

{code}
DB (VecSdsparam)
   ↓
VecSdsparamRepository
   ↓
VecSdsparamDao
   ↓
SdsParameterMapper
   ↓
Paramter Object
   ↓
Set into DAJSONDocument
{code}

----

h2. 7. Mapper Issue & Solution

Problem:
- MapStruct fails due to large size (5302 fields)

Solution:
- Generated Mapper Interface via script
- Manually created Impl class
- @Mapping annotations commented

h2. 15. Key Takeaways

- Flow is DB → Mapper → PCSM → Response
- PARAMTER is most complex block
- CSV + Generator used for scalability
- Manual Impl required due to MapStruct limitation
- Exception handling centralized
